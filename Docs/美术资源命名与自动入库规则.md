# 资源自动入库命名规则

把正式素材按以下目录和名称放入 Unity 工程后，资源扫描器可以识别它们，剧本通过资源 ID 查询。命名正确只代表可以识别，图片内容、透明效果与演出结果仍需检查。

自动入库在 Unity 编辑器中扫描、生成资源登记；运行游戏时使用已经生成的目录，通过 `GetSprite(id, kind)` 等接口精确查询。既有手工资源目录继续兼容，新规则只管理下述资源库，不要求重命名旧图片。

```text
Assets/_Game/ResourceLibrary/<scope>/<kind>/<scope>__<kind>__<subject>__<variant>.<ext>
```

例如：

```text
Assets/_Game/ResourceLibrary/shared/background/shared__background__white_tiger_ridge__day.png
Assets/_Game/ResourceLibrary/shared/portrait/shared__portrait__tangseng__neutral.png
Assets/_Game/ResourceLibrary/fun_01/portrait/fun_01__portrait__wukong_merchant__smile.png
Assets/_Game/ResourceLibrary/fun_01/prop/fun_01__prop__abacus__normal.png
Assets/_Game/ResourceLibrary/fun_01/effect/fun_01__effect__smoke__white.png
Assets/_Game/ResourceLibrary/fun_01/se/fun_01__se__transform__short.wav
```

## 四段名称分别表示什么

| 字段 | 填写规则 | 示例 |
| --- | --- | --- |
| `scope` | `shared` 表示公共资源；其他值是所属路线的 `routeId`。以小写英文字母开头，允许数字和单下划线、单连字符，分隔符不能连续或出现在末尾。 | `shared`、`fun_01` |
| `kind` | 必须是下表中的八种之一，且与所在目录一致。 | `portrait` |
| `subject` | 角色、地点、道具或声音的名称。只用小写英文字母、数字及词间的单下划线。 | `wukong_merchant` |
| `variant` | 表情、时间、状态或其他变体。规则同 `subject`，不能省略。 | `smile`、`night`、`01` |

四段之间使用两个下划线 `__`；一个字段内部只使用单个下划线 `_`。不要使用中文、空格、大写字母或额外的双下划线。`subject` 和 `variant` 不允许连字符。

资源库内必须严格保持 `scope / kind / 文件` 三层结构，不能继续添加“表情”“已完成”等子目录。文件名中的 `scope` 与 `kind` 必须分别等于对应目录名。

## 格式要求

| `kind` | 含义 | 可用格式 |
| --- | --- | --- |
| `background` | 背景 | PNG、JPG、JPEG |
| `portrait` | 角色立绘与表情 | PNG |
| `cg` | 剧情插画 | PNG、JPG、JPEG |
| `prop` | 独立道具画面 | PNG |
| `effect` | 烟雾等特效图片 | PNG |
| `bgm` | 背景音乐 | WAV、OGG |
| `se` | 音效 | WAV、OGG |
| `ambience` | 环境声 | WAV、OGG |

扩展名大小写均可，例如 `.png` 与 `.PNG`。立绘、道具和特效要求 PNG，素材本身也应按画面需要保留透明背景；仅检查名称无法证明图片确实透明。

## 剧本使用的 ID

**资源 ID 就是去掉扩展名后的完整文件名。** 不包含目录，也不包含 `.png` 等扩展名。

```json
{
  "portraitId": "fun_01__portrait__wukong_merchant__smile",
  "portraitSlot": 1,
  "seId": "fun_01__se__transform__short"
}
```

`shared` 资源供路线共用；其他 scope 只说明资源归属。名称解析器不负责判定对应路线是否已经写完、发布，也不把放入素材等同于新增一条可玩的路线。

## 更新与重复文件

- 同一个表情重绘时，替换原文件并保留名称和 Unity `.meta`，剧本中的 ID 就不必改变。
- `neutral_v2` 是一个独立变体名称。系统不会自动去掉 `v2`、选择“最新版本”，也不会根据文件修改时间挑图。
- 同一个背景同时存在 `.png` 和 `.jpg` 两份会产生同一个资源 ID，应只保留一个正式文件。资源扫描器需要将这种情况报告为重复，不能悄悄挑一张。
- 新增真正不同的表情或场景时，使用新的 `variant`；重命名后也要更新剧本引用。
- 源工程文件和未采用的素材放在这套自动资源库之外；PSD、GIF、MP3 等不是这套约定的可入库格式。

## 常见错误

| 错误示例 | 原因 |
| --- | --- |
| `fun_01/portrait/shared__portrait__wukong__smile.png` | 文件名 scope 与目录不一致 |
| `fun_01/cg/fun_01__portrait__wukong__smile.png` | 文件名 kind 与目录不一致 |
| `fun_01/portrait/fun_01__portrait__wukong__smile.jpg` | 立绘必须使用 PNG |
| `fun_01/portrait/fun_01__portrait__悟空__smile.png` | subject 不能用中文 |
| `fun_01/portrait/fun_01__portrait__wukong__happy__02.png` | 多出第五段，应改为 `happy_02` |
| `fun_01/portrait/finished/fun_01__portrait__wukong__smile.png` | 多出子目录 |

这份规则描述自动资源库的命名契约。既有手工资源目录、发布校验、去重与导入设置由相应的集成模块处理，不会由纯名称解析器自行移动或删除文件。
